# Card Optimizer VN

## Cách đưa lên GitHub Pages

1. Giải nén file ZIP này.
2. Upload toàn bộ file/thư mục bên trong lên repo GitHub.
3. Đảm bảo file chính ở thư mục gốc tên là `index.html`.
4. Vào repo > Settings > Pages.
5. Source: Deploy from a branch.
6. Branch: `main` / folder: `/root`, rồi Save.
7. Chờ 1-3 phút để GitHub hiện link web.

Lưu ý: Không upload nguyên file ZIP lên repo nếu muốn chạy web trực tiếp. Cần giải nén rồi upload các file bên trong.
